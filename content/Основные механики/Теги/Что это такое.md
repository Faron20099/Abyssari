Теги — это повторяющиеся свойства способностей, оружия, брони и вообще чего угодно. Теги указывают на дополнительные свойства предмета, помимо его описания.

## Теги оружия


|                                        |                                                                       |
| -------------------------------------- | --------------------------------------------------------------------- |
| Лёгкое, среднее, тяжёлое, сверхтяжёлое | Вес оружия                                                            |
| Простое                                | Порог увеличения урона увеличивается до 20                            |
| Физическое                             | Наносит физический урон                                               |
| Токсичное Ур.#                         | Накладывает отравление                                                |
| Термическое                            | Наносит урон огнём                                                    |
| Зажигательное Ур.#                     | Накладывает горение                                                   |
| Теги классификаций                     | Тип и класс оружия (пока что имеет смысл только в некоторых моментах) |
| Одноручное/двуручное                   | И так ясно                                                            |
|                                        |                                                                       |
